# Bellabeat User Activity Analysis

## Project Overview

I analysed Fitbit fitness-tracking data using Tableau Public to identify patterns in users' daily activity and explore opportunities for Bellabeat to improve user engagement.

The analysis focused on daily steps, calories burned, activity levels, and differences in activity across the week.

## Business Task

The goal of this project was to identify patterns in Fitbit user activity and use those findings to suggest ways Bellabeat could encourage healthier and more consistent daily activity.

### Analysis Questions

- Is there a relationship between daily steps and calories burned?
- How does user activity vary across different days of the week?
- How much time do users spend at different activity levels?
- How are daily step counts distributed among recorded days?
- What opportunities could Bellabeat use these insights to encourage more consistent physical activity?

## Key Findings

- Higher daily step counts were generally associated with higher calorie expenditure.
- Saturday had the highest average daily steps, while Sunday had the lowest.
- Sedentary time was substantially higher than the other activity categories.
- Low-step days were common in the recorded data, although very low step counts may reflect incomplete tracking.

## Recommendations

Based on the findings, I recommend that Bellabeat:

1. Encourage movement throughout the day through personalised reminders.
2. Use achievable daily step goals and progress notifications.
3. Create targeted weekend engagement, particularly around lower-activity days.
4. Use progress tracking, milestones, and activity challenges to encourage consistent movement.

## Limitations

The dataset contains activity records from a relatively small group of Fitbit users, so the findings may not represent the wider population.

Very low step counts may also reflect days when a Fitbit was not worn or did not fully record activity. The analysis identifies relationships and patterns but does not establish cause and effect.

## Conclusion

The analysis suggests that encouraging consistent everyday movement may be a useful opportunity for Bellabeat. Rather than focusing only on high-intensity exercise, Bellabeat could use personalised reminders, achievable activity goals, and progress tracking to help users build more consistent activity habits.
